### Task 2: Fix POTD staleness ceiling

**Files:**
- Modify: `server/src/controllers/nbaController.ts` (`getTodaysPicks` function, ~line 241)

The `findNearestPickDate` helper searches forward indefinitely. If no picks exist for a long stretch (off-season, pipeline outage), it could return a stale future date. Add a 7-day ceiling so POTD returns null rather than week-old picks.

- [ ] **Step 1: Find `findNearestPickDate`**

  In `nbaController.ts` ~line 241, the `getTodaysPicks` function calls `supabaseAdmin.from('pick_results').select('game_date').gte('game_date', today)...`. Locate that query.

- [ ] **Step 2: Add 7-day ceiling to the query**

  The existing query:
  ```typescript
  const { data: dateRow } = await supabaseAdmin
    .from('pick_results')
    .select('game_date')
    .gte('game_date', today)
    .eq('prop_type', 'player')
    .order('game_date', { ascending: true })
    .limit(1)
    .single();
  ```

  Replace with:
  ```typescript
  const sevenDaysOut = new Date();
  sevenDaysOut.setDate(sevenDaysOut.getDate() + 7);
  const ceiling = sevenDaysOut.toISOString().slice(0, 10);

  const { data: dateRow } = await supabaseAdmin
    .from('pick_results')
    .select('game_date')
    .gte('game_date', today)
    .lte('game_date', ceiling)
    .eq('prop_type', 'player')
    .order('game_date', { ascending: true })
    .limit(1)
    .single();
  ```

- [ ] **Step 3: Build and test**

- [ ] **Step 4: Commit**
